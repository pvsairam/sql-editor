## Write and run SQL

Open a **New SQL Worksheet** and type a query. Then:

- **Ctrl+Enter** (Cmd+Enter on macOS) runs the statement under the cursor - or your selection.
- **F5** runs every statement in the file, one result tab each.
- `:name` bind variables are prompted for. `DESC table_name` works too.

Completion knows common HCM / ERP / SCM tables, and the **Schema** view lets you browse the live dictionary.
